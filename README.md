# Rothvil Group Holdings — 2026 Visual Refresh

Updated editorial copy, full-viewport interactive carousel, fluid scrolling and new full-bleed photography. All original business-profile image assets have been removed.

## Photography
The site uses new **external Unsplash photographic URLs**, not the original profile images. These are illustrative photographs, **not Rothvil project records**. An internet connection is required to display them. Before deploying to production, download licensed high-resolution photographs into `public/images/` and replace the remote image references in `app/page.tsx` for reliable self-hosting. Review image licensing and suitability.
